# Cloudflare Workers → Vercel Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate AiimanFolio.Pro deployment from Cloudflare Workers to Vercel Node.js serverless, preserving cache headers and SSR error normalization.

**Architecture:** Disable the CF plugin via `cloudflare: false` in `vite.config.ts` (no eject needed). TanStack Start v1.167 builds to `dist/server/` (Node.js bundle) and `dist/client/` (static assets). A thin `api/index.ts` Vercel function wraps the existing web fetch handler with a Node.js adapter. Vercel routes static files from `dist/client/` and falls back to the serverless function for SSR.

**Tech Stack:** TanStack Start v1.167 (Vite environments API), `@lovable.dev/vite-tanstack-config` (with `cloudflare: false`), Vercel Node.js serverless, Node.js `IncomingMessage`/`ServerResponse` → `Request`/`Response` adapter.

## Task 3: Create api/index.ts — Vercel serverless function

**Files:**
- Create: `api/index.ts`

This function wraps the TanStack Start web fetch handler for Vercel's Node.js runtime.
It imports from `../dist/server/server.js` which is generated by `bun run build`.
Vercel bundles this function (and its imports) after the build step completes.

- [ ] **Step 1: Create api/index.ts**

```ts
import type { IncomingMessage, ServerResponse } from "node:http";

type FetchHandler = {
  fetch: (
    request: Request,
    env: unknown,
    ctx: { waitUntil: (p: Promise<unknown>) => void },
  ) => Promise<Response>;
};

let serverEntry: FetchHandler | undefined;

async function getEntry(): Promise<FetchHandler> {
  if (!serverEntry) {
    // Imported after build — dist/server/server.js is created by `bun run build`
    const mod = (await import("../dist/server/server.js")) as {
      default: FetchHandler;
    };
    serverEntry = mod.default;
  }
  return serverEntry;
}

function toWebRequest(req: IncomingMessage): Request {
  const proto =
    (req.headers["x-forwarded-proto"] as string | undefined) ?? "https";
  const host = req.headers.host ?? "localhost";
  const url = `${proto}://${host}${req.url ?? "/"}`;

  const headers = new Headers();
  for (const [key, value] of Object.entries(req.headers)) {
    if (value == null) continue;
    headers.set(key, Array.isArray(value) ? value.join(", ") : value);
  }

  const method = req.method ?? "GET";
  const hasBody = method !== "GET" && method !== "HEAD";

  if (!hasBody) {
    return new Request(url, { method, headers });
  }

  // Stream the request body
  const body = new ReadableStream<Uint8Array>({
    start(controller) {
      req.on("data", (chunk: Buffer) => controller.enqueue(chunk));
      req.on("end", () => controller.close());
      req.on("error", (err) => controller.error(err));
    },
  });

  return new Request(url, {
    method,
    headers,
    body,
    // @ts-expect-error - required for streaming bodies in Node.js fetch
    duplex: "half",
  });
}

async function sendWebResponse(
  webRes: Response,
  res: ServerResponse,
): Promise<void> {
  res.statusCode = webRes.status;
  webRes.headers.forEach((value, key) => {
    res.setHeader(key, value);
  });

  if (webRes.body) {
    const reader = webRes.body.getReader();
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      res.write(value);
    }
  }

  res.end();
}

export default async function handler(
  req: IncomingMessage,
  res: ServerResponse,
): Promise<void> {
  try {
    const entry = await getEntry();
    const request = toWebRequest(req);
    const response = await entry.fetch(request, {}, { waitUntil: () => {} });
    await sendWebResponse(response, res);
  } catch (err) {
    console.error("[vercel-handler] unhandled error:", err);
    res.statusCode = 500;
    res.setHeader("content-type", "text/plain");
    res.end("Internal Server Error");
  }
}
```

## Troubleshooting

**Build fails: "Cannot find module '@cloudflare/vite-plugin'"**
→ The `@lovable.dev/vite-tanstack-config` tries to import CF plugin even with `cloudflare: false`.
→ Fix: Check that `cloudflare: false` is the TOP-LEVEL key in `defineConfig({...})`, not inside `tanstackStart`.

**Vercel function 500: "Cannot find module '../dist/server/server.js'"**
→ The server bundle wasn't built before Vercel deployed the function.
→ Fix: Verify `buildCommand: "bun run build"` in `vercel.json`. Check Vercel build logs show the TanStack Start build output.

**SSR pages return blank/error**
→ The `#tanstack-router-entry` or `#tanstack-start-entry` virtual imports weren't resolved.
→ Fix: These are resolved by the Vite build. Check `dist/server/server.js` exists and is non-empty. Re-run `bun run build`.

**Supabase queries fail in production**
→ Environment variables not set in Vercel dashboard.
→ Fix: Double-check all env vars in Project Settings → Environment Variables. Note: `VITE_` prefix vars must also be added without `VITE_` prefix for server-side access.
